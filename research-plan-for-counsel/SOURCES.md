# Sources and credits

Written by Fully Powered AI in its own words. The starting idea comes from the research starter in the law-school clinic plugin published in anthropics/claude-for-legal (Apache-2.0). In that method a student's issue is first made specific; the clinic's own vetted documents come before anything else; the kinds of material worth searching are set out with some starting queries; research the student has already done is checked against that outline to show what is still missing; every citation carries a tag saying where it came from; and a banner at the top warns that nothing in the output has been checked. That method still suggests statutes, flagged as unverified. This workflow template suggests none. Fully Powered AI built the firm version: a plan prepared for one named lawyer; the partner's question split into sub-questions by fixed rules, keeping the partner's own words; every fact quoted and located, and set against the sub-questions only by the words they share, so the plan makes no call on which facts matter; every document mentioned but not supplied listed; the firm's notes matched from an exported index with stated column headers and a stop on any mismatch; search terms built only from words already in the inputs; no authority at all unless the research supplied contains it, copied exactly with what its reference lacks; and a confirmation list the lawyer signs. The heading phrase "leads, not authorities" is taken from that method's banner; no other third-party text is reused.
