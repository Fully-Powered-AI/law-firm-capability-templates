# Consultation fact record: one trial on its invented example

- **Product:** Claude, run in Claude Code
- **Model:** Claude Opus 5.5
- **Date:** 2026-11-11
- **Runs:** one recorded run on the template as revised after an independent review on 11 November, and its example, followed by eight pressure tests. It replaces the record of an earlier run the same day on the previous revision.

The inputs are the invented example published with this template. Ines Varga, Shop A, Contractor B, Supplier C, Company D, the firm's people and every figure are invented, and no client data was used. This is a record of one run on that example. It is not a test in any firm's environment, and it is not a lawyer's review: nobody who has read this record or the template is a lawyer.

## Why there is a new run

An independent review of the previous revision failed it on four points: the head of the output did not say that the record decides nothing about legal meaning, merit, validity, privilege, conflicts or deadlines, and left "signed" out; the instruction block named too few kinds of drafting it refuses; it never refused to say that a name is clear, whether anything is privileged, what a document means or whether anything is valid; and it let the assistant ask who verifies and still draft. The earlier run also left seven points the rules did not settle. The template was revised for all of these, and the output gained three fixed lines: the head line on deciding nothing, a line under section 1 saying no name has been searched or cleared, and a line under section 2 saying "CONFIRMED" means only that the client stated the date.

One run on an interim wording of this revision is not recorded in full. It followed the seven new rules but left three more points open: words that only say who someone is (Owen as site lead) made into statements, "the café next door" listed as an organisation not named, and "no one from Contractor B has come since" split off with "since" as its date. A rule was added for each before the run recorded here.

## Inputs used

Exactly the three inputs in [the example](example.md), and nothing else:

- the request from Priya Lund, paralegal, dated 4 November 2026, asking for the record for Tomas Reyhill, intake attorney, with the consultation details, the note that the notes are saved to the intake folder and that TR's own comments are in square brackets, and no firm format;
- the party list from the inquiry (Ines Varga, Shop A, Contractor B) and the two documents the client supplied by email on 3 November 2026, by file name;
- the consultation notes, 15 numbered paragraphs under a two-line heading.

How the run was set up: a separate session with no tools and no project files was given the template's instruction block, the output format and the lines on how to fill it in as its instructions, and the three inputs as one message. It did not see the rest of the template, the example's output or the earlier record. The session that revised the template assembled those inputs and wrote this record.
